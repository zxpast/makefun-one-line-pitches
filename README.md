One sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> Just describe the app you've been imagining in plain words, and an AI agent on make.fun builds it while you watch — no code, no setup, and if it isn't quite right, just say so and it changes it until it feels like yours.

The pitch gives the friend a concrete reason to say yes now: their idea, in their own words, becomes a real app they can watch being built, with no code and no setup — and they stay in charge, because they can ask for changes in plain words until it feels like theirs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` assembles the pitch from four fixed parts and writes `/output/entry.txt` (220 code points, inside the 1–240 gate). Node 22 standard library only, fully deterministic: same bytes on every run — no clock, no randomness, no network.
